# Student Grade Management System

## Project Description

The Student Grade Management System is a Python-based application that calculates a student's total marks, percentage, grade, and pass/fail status.

The project demonstrates Python variables, data types, strings, conditions, functions, loops, user input, and modules.

## Features

- Accepts student name
- Accepts marks for five subjects
- Calculates total marks
- Calculates percentage
- Determines grade
- Checks pass/fail status
- Uses reusable functions
- Uses a separate Python module

## Subjects

The system accepts marks for:

1. Python
2. Mathematics
3. English
4. Computer Science
5. AI

## Project Files

- `student_grade_system.py` – Main program
- `grade_utils.py` – Module containing reusable functions

## Grade Criteria

| Percentage | Grade |
|---|---|
| 90 and above | A+ |
| 80–89 | A |
| 70–79 | B |
| 60–69 | C |
| 50–59 | D |
| Below 50 | F |

## Pass/Fail Criteria

A student passes when the marks in every subject are at least 35.

If the student scores below 35 in any subject, the result is FAIL.

## Sample Output

The program was tested with different marks to verify both PASS and FAIL conditions.
